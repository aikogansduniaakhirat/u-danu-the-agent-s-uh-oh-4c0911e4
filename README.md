The one word an agent says when it has no idea what to do: `improvising`. Not
`error`, not `404`, not `hallucinating` — those are the words it says when it
still thinks it can hide it. `improvising` is the word that admits the floor
has gone and the machine is going to keep talking anyway.

`main.ts` writes that word, once, to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt`,
after checking it against the bounty's gate (UTF-8, 1–99 characters, not only
white space, single line, none of the brief's stale obvious picks).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Output is a pure constant: two runs produce byte-identical files, so the
grader's twice-run check is safe.
